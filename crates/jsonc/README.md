# jsonc

Port of [`microsoft/node-jsonc-parser`](https://github.com/microsoft/node-jsonc-parser)
(4.0.0-next.2, de0d2fd).

Scanner, error-tolerant parser, `parse_tree`, `visit`, `get_location`,
`format`, `modify`, `apply_edits`, `strip_comments`. No LSP dependency.

Differences from upstream: [`docs/differences/jsonc.md`](../../docs/differences/jsonc.md).
