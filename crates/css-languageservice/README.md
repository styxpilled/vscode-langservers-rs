# css-languageservice

Port of [`microsoft/vscode-css-languageservice`](https://github.com/microsoft/vscode-css-languageservice)
(7.0.0-next.2, 9f0aa50), with `beautify-css.js` of js-beautify 2.0.3.

CSS, SCSS and Less: parser, lint, completion, hover, navigation (definition,
references, highlights, symbols, links, colors, rename), code actions, folding,
selection ranges, path completion and formatting.

Differences from upstream: `css-*.md` in [`docs/differences/`](../../docs/differences).
Design: [`docs/design.md`](../../docs/design.md).
