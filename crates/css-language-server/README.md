# css-language-server

Port of the CSS server of [`microsoft/vscode`](https://github.com/microsoft/vscode)
(`extensions/css-language-features/server`, `main`, 1448348). Binary:
`vscode-css-language-server --stdio`.

Also a library: the HTML server uses its settings and file system parts.
