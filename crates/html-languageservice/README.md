# html-languageservice

Port of [`microsoft/vscode-html-languageservice`](https://github.com/microsoft/vscode-html-languageservice)
(6.0.0-next.2, 04a0299), with `beautify-html.js` of js-beautify.

Scanner, parser, completion, path completion, hover, folding, highlights,
links, symbols, rename, linked editing, matching tag, selection ranges and
formatting.

Differences from upstream: [`docs/differences/html-service.md`](../../docs/differences/html-service.md),
[`docs/differences/html-formatter.md`](../../docs/differences/html-formatter.md).
Design: [`docs/design.md`](../../docs/design.md).
