# json-languageservice

Port of [`microsoft/vscode-json-languageservice`](https://github.com/microsoft/vscode-json-languageservice)
(6.0.0-next.4, bf6a8b2).

Parser, JSON Schema validation (drafts 4, 6, 7, 2019-09 and 2020-12),
completion, hover, document symbols, colors, folding, selection ranges, links,
formatting and sort. Schemas load through a synchronous request function.

Differences from upstream: [`docs/differences/json-languageservice.md`](../../docs/differences/json-languageservice.md).
Design: [`docs/design.md`](../../docs/design.md).
